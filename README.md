# Tienda Online API - Práctica Backend

API REST desarrollada con NestJS, TypeORM y PostgreSQL para la gestión de una tienda online. Implementa arquitectura N-capas, validaciones y documentación interactiva.

## Tecnologías Utilizadas

* **Framework:** NestJS
* **Base de Datos:** PostgreSQL
* **ORM:** TypeORM
* **Validaciones:** class-validator & class-transformer
* **Documentación:** Swagger & Scalar

## Requisitos Previos

Antes de ejecutar el proyecto, asegúrate de tener instalado:

* [Node.js](https://nodejs.org/) (v16 o superior)
* [PostgreSQL](https://www.postgresql.org/)

## Configuración y Ejecución

Sigue estos pasos para correr el proyecto localmente:

### 1. Base de Datos
Crea una base de datos en PostgreSQL llamada `tienda_online` y importa la base de datos que esta dentro de los archivos llamado "base de datos.sql"
y por ultimo ejecutar con:

npm install ts-node --save-dev

npx ts-node src/main.ts

http://localhost:3000/reference
